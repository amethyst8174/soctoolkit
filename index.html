Why it's safe to paste real reports here
  • Processed on your device. Extraction and query building run as JavaScript in this tab. There is no server and no AI model behind this page.
  • The browser blocks outbound traffic. A Content Security Policy forbids this page from sending requests or submitting forms, so data cannot leave even by mistake.
  • Lookups are local. Country, ASN, Tor exit and FireHOL checks use data files shipped with the page. Nothing is queried live.
  • Nothing persists. No cookies or browser storage. Leaving or reloading the page wipes everything.
  • Verify it yourself. Open DevTools: the Network tab stays empty after you paste. The full source is on GitHub.
